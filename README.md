# Stock Calculator

一个打开即用、不会保存输入数据的股票做 T 收益计算器。支持桌面端和移动端，可配置佣金、最低佣金、印花税及过户费。

## 功能

- 实时计算毛差价、净收益、收益率和每股净收益
- 计算买卖双边手续费与保本卖出价
- 买卖数量不一致时按已匹配数量计算并明确提示
- 所有数据仅存在于当前页面内，刷新或关闭后清空
- 响应式布局，兼容 PC 与手机

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可。

## 测试与构建

```bash
npm test
npm run build
```

## 计算口径

当买入和卖出数量不一致时，使用两者中的较小值作为已完成交易数量。净收益为卖出金额减去买入金额及买卖双方费用；净收益率以包含买入费用的总成本为基数。

页面内的费率默认值仅作常用示例，实际费用请以券商交割单为准。
